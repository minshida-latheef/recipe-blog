# 🍳 FreshEats - Frontend Recipe Blog & Utility Application

A modern, responsive, **frontend-only website** featuring a landing gateway, interactive recipe search console, dark mode styling, and dynamic detail sliders. This application is lightweight, fast, and runs entirely inside the client-side browser using standard Vanilla web languages.

---

## ✨ Features

- **Multi-Page Architecture:** Includes a welcoming marketing landing view (`home.html`) that cleanly pathways users into the core utility workspace (`index.html`).
- **Dynamic Content Injection:** Recipes are loaded on-the-fly dynamically via JavaScript objects, eliminating static HTML duplication.
- **Real-Time Database Search:** Instant live filtering across dish titles and categorical tags via an integrated search input field.
- **Interactive Light & Dark Mode:** Context-aware dynamic theme toggling driven completely by native CSS custom properties.
- **Component Modals:** Seamless popup viewport screens overlaying full structural ingredient profiles and directions.
- **Responsive Layout Architecture:** Built using clean CSS Flexbox alignments and grid auto-fill rules optimized for mobile and desktop viewpoint widths.

---

## 🛠️ Technology Stack

- **HTML5:** Semantic architecture layout structures.
- **CSS3 Grid & Flexbox:** Modular positioning layouts, dynamic custom attribute values, and layout fluid movement.
- **Vanilla JavaScript (ES6+):** Array operations, structural DOM mutation listeners, and state configuration toggles.

## 🚀 Quick Local Setup Instructions

Because this is a completely decoupled frontend-only static web structure, you **do not need** to install third-party server environments like Node.js, Docker, or Python to test it out.

1. **Clone or Download** the folder structure to your local workstation.
2. Ensure all files (`home.html`, `index.html`, `style.css`, `app.js`) are saved together in that **same folder directory**.
3. Double-click the `home.html` file to instantly open your website inside Google Chrome, Safari, Firefox, or Brave.
